Definición de Polinomios

¿Qué es un Polinomio?

Definición: Un polinomio es una expresión de la forma:

P(x) = a₀ + a₁x + a₂x² + ... + aₙxⁿ

Donde:

  • x es la variable o indeterminada (los exponentes son enteros no negativos)
  • a₀, a₁, a₂, ..., aₙ se llaman coeficientes (números reales)
  • a₀ es el término independiente
  • aₙ es el coeficiente principal
  • Si aₙ ≠ 0, n es el grado de P(x)

Ejemplos:

  • P(x) = 5x³ - 2x² + 3x + 4 → Grado 3
  • Q(x) = 4 - x → Grado 1
  • V(x) = 2x⁷ - 6x³ + 7x + 4 → Grado 7
  • S(x) = 23 → Grado 0

Clasificación según número de términos:

  • Monomio: 1 término (ej: S(x) = 23)
  • Binomio: 2 términos (ej: Q(x) = 4 - x)
  • Trinomio: 3 términos (ej: P(x) = 5x³ - 2x² + 3x + 4)

b) Q(x) = 7

Respuestas:

b) Grado 0 (polinomio constante)

c) Grado 6 (el mayor exponente es 6)

Ejercicio 3:
Determinar los valores de m, n, r y s para que T(x) = G(x):
T(x) = -½x⁵ + 2x³ - 2x² + 5
G(x) = (m-3)x + (2n+m)x² + (r+s)x³ + (n-r)x + (s-n)

Resolución: Igualamos coeficientes de igual grado:

• x⁵: -½ = 0 (no hay término en G) → No coincide
• x⁴: 0 = m-3 → m = 3
• x³: 2 = r+s
• x²: -2 = 2n+m → -2 = 2n+3 → n = -5/2
• x¹: 0 = n-r → r = n = -5/2
• x⁰: 5 = s-n → 5 = s-(-5/2) → s = 5/2

Verificando r+s = -5/2 + 5/2 = 0 ≠ 2

Solución: No existen valores que satisfagan la igualdad

Operaciones con Polinomios

Suma y Resta de Polinomios

Suma: Se suman los coeficientes de los términos de igual grado.

A(x) + B(x) = (a₀+b₀) + (a₁+b₁)x + (a₂+b₂)x² + ...

Propiedades:

  • Conmutativa: A(x) + B(x) = B(x) + A(x)
  • Asociativa: (A+B)+C = A+(B+C)
  • Elemento neutro: El polinomio nulo (todos coeficientes = 0)
  • Elemento opuesto: Para todo A(x) existe -A(x) tal que A(x) + (-A(x)) = 0

Resta: P(x) - S(x) = P(x) + [-S(x)]

Restar un polinomio equivale a sumar su opuesto.

📝 Ejercicios - Suma y Resta

Ejercicio 1:
Dados:
A(x) = -½x⁵ + 2x³ - 2x² + 5
B(x) = -4x⁵ + 7x⁴ - x + 3
Calcular: A(x) + B(x)

Resolución:

A(x) + B(x) = (-½x⁵ + 2x³ - 2x² + 5) + (-4x⁵ + 7x⁴ - x + 3)

= (-½-4)x⁵ + 7x + 2x³ - 2x² - x + (5+3)

= -9/2x⁵ + 7x⁴ + 2x³ - 2x² - x + 8

Solución: -9/2x⁵ + 7x⁴ + 2x³ - 2x² - x + 8

Ejercicio 2:
Dados:
P(x) = 5/2x³ + 2x² - 3x - 2
S(x) = 3x - 4x² - 5x + 3
Calcular: P(x) - S(x)

Resolución:

P(x) - S(x) = P(x) + [-S(x)]

= (5/2x³ + 2x² - 3x - 2) + (-3x + 4x² + 5x - 3)

= -3x⁴ + 5/2x³ + (2+4)x² + (-3+5)x + (-2-3)

= -3x⁴ + 5/2x³ + 6x² + 2x - 5

Solución: -3x⁴ + 5/2x³ + 6x² + 2x - 5

Multiplicación de Polinomios

Propiedad: Multiplicamos cada término de un polinomio por cada término del otro.

(a₀ + a₁x)(b₀ + b₁x) = a₀b₀ + (a₀b₁+a₁b₀)x + a₁b₁x²

Grado del producto: gr(P·Q) = gr(P) + gr(Q)

Propiedades:

  • Conmutativa: A(x)·B(x) = B(x)·A(x)
  • Asociativa: (A·B)·C = A·(B·C)
  • Elemento neutro: E(x) = 1
  • Distributiva: A(x)·[B(x)+C(x)] = A(x)·B(x) + A(x)·C(x)

Ejercicios - Multiplicación

Ejercicio 3:
Calcular: (3x² - x + 1) · (2x² - x + 4)

Resolución:

= 3x²(2x² - x + 4) - x(2x² - x + 4) + 1(2x² - x + 4)

= 6x⁴ - 3x³ + 12x² - 2x³ + x² - 4x + 2x² - x + 4

= 6x⁴ + (-3-2)x³ + (12+1+2)x² + (-4-1)x + 4

= 6x⁴ - 5x³ + 15x² - 5x + 4

Solución: 6x⁴ - 5x³ + 15x² - 5x + 4

División de Polinomios

División Entera de Polinomios

Algoritmo:

  1. Ordenar ambos polinomios según potencias decrecientes de x
  2. Completar el dividendo si faltan términos
  3. Dividir el primer término del dividendo por el primer término del divisor
  4. Multiplicar el resultado por todo el divisor
  5. Restar este producto del dividendo
  6. Repetir hasta obtener un resto de grado menor que el divisor
D(x) = d(x) · C(x) + R(x)
donde gr(R) < gr(d) o R(x) = 0

📝 Ejercicios - División

Ejercicio 1:
Dividir: (3x + 2x³ - 4x² + 4x - 4) (x³ - 2x²)

Resolución:

3x⁴ + 2x³ - 4x² + 4x - 4 | x³ - 2x²
-3x⁴ + 6x³ | 3x + 8
──────────────────────
8x³ - 4x² + 4x - 4
-8x³ + 16x²
──────────────────
12x² + 4x - 4

Cociente: C(x) = 3x + 8

Resto: R(x) = 12x² + 4x - 4

Verificación: (x³-2x²)(3x+8) + (12x²+4x-4) = 3x⁴+2x³-4x²+4x-4 ✓

Regla de Ruffini

Cuándo usar: Cuando dividimos por un polinomio de la forma (x ± a)

Procedimiento:

  1. Escribir los coeficientes del dividendo ordenado y completo
  2. Escribir el opuesto de "a" en el ángulo
  3. Bajar el primer coeficiente
  4. Multiplicar por "a" y sumar al siguiente coeficiente
  5. Repetir hasta el final
  6. El último número es el resto, los demás son coeficientes del cociente

Factorización de Polinomios

Métodos de Factorización

a) Factor Común:

P(x) = 3x² - 18x = 3x(x - 6)

b) Diferencia de Cuadrados:

x² - a² = (x + a)(x - a)

Ejemplos:

  • x² - 25 = (x + 5)(x - 5)
  • x⁴ - 36 = (x² + 6)(x² - 6)

c) Trinomio Cuadrado Perfecto:

x² + 2ax + a² = (x + a)²
x² - 2ax + a² = (x - a)²

Ejemplo: x² + 10x + 25 = (x + 5)²

d) Cuatrinomio Cubo Perfecto:

x³ + 3ax² + 3a²x + a³ = (x + a)³

Ejemplo: x³ + 6x² + 12x + 8 = (x + 2)³

e) Factor Común por Grupos:

7x⁵ - 14x + 5x - 10 = 7x⁴(x-2) + 5(x-2) = (7x+5)(x-2)

📝 Ejercicios - Factorización

Ejercicio 1:
Factorizar: P(x) = x⁴ - x

Resolución:

P(x) = x⁴ - x

= x(x³ - 1)

= x(x - 1)(x² + x + 1)

Solución: x(x-1)(x²+x+1)

Ejercicio 2:
Factorizar: Q(x) = 5x³ - 10x² + 5x - 10

Resolución:

Q(x) = 5x³ - 10x² + 5x - 10

= 5x²(x - 2) + 5(x - 2)

= (5x² + 5)(x - 2)

= 5(x² + 1)(x - 2)

Solución: 5(x²+1)(x-2)

Ejercicio 3:
Factorizar: T(x) = x⁴ - 2x³ + x²

Resolución:

T(x) = x - 2x³ + x²

= x²(x² - 2x + 1)

= x²(x - 1)²

Solución: x²(x-1)²

Ejercicio 4:
Factorizar: P(x) = x³ - 6x² + 12x - 8

Resolución:

Observamos que es un cubo perfecto:

(x)³ = x³

(2)³ = 8

3·x²·2 = 6x² ✓

3·x·2² = 12x ✓

P(x) = (x - 2)³

Solución: (x-2)³

Teorema del Resto y Raíces

Valor Numérico y Raíces

Valor Numérico: Es el número que se obtiene reemplazando x por un valor a y efectuando los cálculos.

Ejemplo: P(x) = x² - 5x + 6

  • P(1) = 1 - 5 + 6 = 2
  • P(2) = 4 - 10 + 6 = 0
  • P(-1) = 1 + 5 + 6 = 12

Raíz de un Polinomio:

x = a es raíz de P(x) ⟺ P(a) = 0

Ejemplo: x = 2 es raíz de P(x) = x² - 5x + 6 porque P(2) = 0

Teorema del Resto

Enunciado: El resto de la división de un polinomio P(x) por otro de la forma (x - a) es igual a P(a).

P(x) ÷ (x-a) → Resto = P(a)

Consecuencia: P(x) es divisible por (x-a) si y solo si P(a) = 0

Ejercicios - Teorema del Resto

Ejercicio 1:
Averiguar si A(x) = x³ - 8 es divisible por B(x) = x + 2

Resolución:

B(x) = x + 2 = x - (-2), entonces a = -2

Calculamos A(-2) = (-2)³ - 8 = -8 - 8 = -16

Como A(-2) ≠ 0, entonces NO es divisible

Solución: No es divisible. Resto = -16

Ejercicio 2:
Averiguar si A(x) = x² - 5x + 6 es divisible por B(x) = x - 2

Resolución:

Calculamos A(2) = 2² - 5(2) + 6 = 4 - 10 + 6 = 0

Como A(2) = 0, entonces SÍ es divisible

Solución: Sí es divisible. Resto = 0

Ejercicio 3:
Hallar el valor de h sabiendo que -4 es raíz de:
M(x) = 6x⁵ - 7x³ + 5x² + 11x + h

Resolución:

Si -4 es raíz, entonces M(-4) = 0

M(-4) = 6(-4)⁵ - 7(-4)³ + 5(-4)² + 11(-4) + h = 0

= 6(-1024) - 7(-64) + 5(16) - 44 + h = 0

= -6144 + 448 + 80 - 44 + h = 0

= -5660 + h = 0

h = 5660

Solución: h = 5660

Ejercicio 4:
Encontrar las raíces de P(x) = x⁴ - 4x³ + x² + 8x - 6
(Pista: probar con divisores del término independiente)

Resolución:

Divisores de -6: ±1, ±2, ±3, ±6

P(1) = 1 - 4 + 1 + 8 - 6 = 0 ✓ → x = 1 es raíz

Dividimos por (x-1) usando Ruffini:

1 -4 1 8 -6 | 1
1 -3 -2 6
──────────────────
1 -3 -2 6 0

Q(x) = x³ - 3x² - 2x + 6

Q(3) = 27 - 27 - 6 + 6 = 0 ✓ → x = 3 es raíz

Dividimos Q(x) por (x-3):

1 -3 -2 6 | 3
3 0 -6
─────────────
1 0 -2 0

R(x) = x² - 2 = (x+√2)(x-√2)

Raíces: x = 1, x = 3, x = √2, x = -√2
