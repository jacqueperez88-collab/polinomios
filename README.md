# 📐 Polinomios - Matemática General (UNComa)

Bienvenido al repositorio del material educativo interactivo sobre **Polinomios**, diseñado especialmente para estudiantes de la Facultad de Informática de la Universidad Nacional del Comahue (UNComa).

🔗 **Ver la página en vivo:** [https://jacqueperez88-collab.github.io/polinomios/](https://jacqueperez88-collab.github.io/polinomios/)

---

## 📚 Descripción
Este proyecto es una página web didáctica, visual e interactiva que resume la teoría y ofrece ejercicios prácticos resueltos paso a paso sobre polinomios. El contenido está basado en los apuntes oficiales de la cátedra de Matemática General, adaptado a un formato digital moderno para facilitar el estudio y la autoevaluación.

## ✨ Características Principales
- 🎨 **Diseño Visual Atractivo**: Paleta de colores pasteles (lavanda, durazno, menta y azul claro) cuidadosamente elegida para reducir la fatiga visual y diferenciar este módulo de otros.
- 🧮 **Renderizado LaTeX Profesional**: Todas las fórmulas matemáticas, fracciones y tablas de Ruffini están escritas en LaTeX y renderizadas en tiempo real usando **MathJax**, garantizando una tipografía académica impecable.
- 🔄 **Interactividad**: Botones para mostrar/ocultar las resoluciones, permitiendo a los estudiantes intentar los ejercicios por su cuenta antes de corroborar sus resultados.
- 📱 **Diseño Responsive**: Se adapta perfectamente a computadoras de escritorio, tablets y teléfonos móviles.

## 📂 Temas Cubiertos
La página está organizada en 5 secciones principales de navegación:
1. **Definiciones**: Concepto de polinomio, grado, coeficientes y clasificación.
2. **Operaciones**: Suma, resta y multiplicación de polinomios con sus propiedades.
3. **División**: Algoritmo de división entera y Regla de Ruffini.
4. **Factorización**: Casos de factoreo (factor común, diferencia de cuadrados, trinomio y cuatrinomio cuadrado/cubo perfecto, y factor común por grupos).
5. **Teoremas**: Valor numérico, raíces de un polinomio y el Teorema del Resto.

## 🛠️ Tecnologías Utilizadas
- **HTML5**: Estructura semántica del contenido.
- **CSS3**: Estilos personalizados, gradientes, animaciones suaves y diseño *mobile-first*.
- **JavaScript (Vanilla)**: Lógica ligera para la navegación entre pestañas y el toggle de las soluciones.
- **MathJax**: Librería JavaScript para el renderizado de fórmulas matemáticas en LaTeX (`$ ... $` y `$$ ... $$`).

## 🚀 Cómo usar este recurso
1. Accede directamente a la página publicada a través del enlace de [GitHub Pages](https://jacqueperez88-collab.github.io/polinomios/).
2. Utiliza el menú de navegación superior para saltar entre los diferentes temas.
3. Lee la teoría resumida en las cajas de color.
4. Intenta resolver los ejercicios propuestos en tu cuaderno.
5. Haz clic en el botón **"Ver Solución"** para desplegar el desarrollo paso a paso y verificar tu resultado.
